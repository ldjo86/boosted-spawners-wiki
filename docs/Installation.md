# Installer Boosted Spawners — 50 Block Activation

**Version(s) repérée(s) :** spawns_50blocs_optimise.zip.

1. Télécharge le ZIP compatible depuis CurseForge.
2. Place-le dans le dossier datapacks/ de ton monde.
3. Exécute /reload ou redémarre le serveur.
4. Confirme sa présence avec /datapack list.
5. Teste ses effets sur une copie du monde.

## Avant d'installer

Page CurseForge consultée ; le ZIP local n'a pas été retrouvé. Les 50 blocs sont une annonce, pas une vérification indépendante.

Vérifie la page CurseForge : https://www.curseforge.com/minecraft/data-packs/boosted-spawners-50-block-activation.
